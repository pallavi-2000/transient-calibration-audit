Calibration of Production Transient Alert Brokers:
Preparing Decision Infrastructure for LSST

Can broker confidence scores be trusted for automated follow-up decisions?

1Motivation

“When a broker reports 80% confidence, is it actually correct 80% of the time?”
Millions of alerts→ Broker class probabilities→ Gates & rankings→ Follow-up decisions→ Limited telescope resources
  • Rubin/LSST alert volumes cannot be inspected manually; broker probabilities feed rankings, automated filters, human review and follow-up requests.
  • A classifier may rank the correct class first while reporting unreliable confidence values.
  • Miscalibration either rejects useful candidates or auto-accepts unreliable labels.
UnderconfidenceCorrect classifications score too low → useful objects fail fixed probability gates.
OverconfidenceIncorrect classifications score too high → unreliable labels trusted automatically.
A functioning classifier is not automatically functioning decision infrastructure.

3Calibration-aware selective-classification pipeline

1
Compare labels. ALeRCE top-ranked class vs independent spectroscopic label.
2
Define correctness. Correct = 1 if top-1 class matches spectroscopy, else 0.
3
Audit calibration. Predictions near confidence 0.7 should be correct ≈ 70% of the time.
ECE = Σb (nb/N) · | acc(b) − conf(b) |
4
Recalibrate. Held-out temperature scaling repairs the probability scale — it never changes the top-ranked class.
p̃ = softmax( log p / T )
5
Uncertainty features. Top-1, top-2, margin, normalised entropy, transient-branch mass, conditional transient confidence, non-transient competition.
6
Train the checker. Logistic regression estimating P(top-1 is correct): learned_shape (shape features) and learned_full (all 15 calibrated probabilities + shape).
7
Accept or defer. High score → auto-accept label. Low score → defer for more detections, another broker, human review, or justified spectroscopy.
Chow’s rule:  defer ⇔ P̂(error) > cdefer  (Chow 1970)
“Defer” does not automatically mean spectroscopy.

Evaluation: five-fold out-of-fold (train 80% / test unseen 20%) · paired stratified bootstrap · ROC-AUC · AURC & risk–coverage · fixed-threshold operating points · TDE stress test. Post-hoc selective classification — not a jointly trained learning-to-defer system, not a deployed real-time LSST pipeline.

4Calibration and error detection are different

100 predictions at confidence 0.8 → 80 correct, 20 incorrect.

A group may be perfectly calibrated even when the score cannot identify which individual predictions are wrong.

Correctness ranking (ROC-AUC)

The shape-only model does not clearly beat the class-rate control — the full 15-class probability vector supplies the additional signal.

Calibration changes threshold meaning

Calibration mainly repairs the numerical probability scale — it does not create new correct classifications or substantially reorder objects.

Class-wise ECE: one global correction is not enough

SNIa/SNIbc: accurate but strongly underconfident — repaired. SNII: calibration worsened by the global correction. SLSN: only 55 objects. Class-dependent miscalibration remains.

Missing classes need a separate novelty channel

TDEs deferred at the 80%-coverage cutoff. None of the confidence-based policies reliably detected the taxonomy gap (n = 30; intervals overlap).

The policy that works best for ordinary in-taxonomy errors is not necessarily the best novelty detector.
Known-class channel: calibrated probability + checker Novelty channel: explicit OOD / anomaly detector

Simple cost model (deferral cost 0.20, unit error cost): learned_full 0.142/object · class control 0.161 · calibrated conf. 0.179 · raw 0.199 · defer-all 0.200. Generic costs — not a class-weighted telescope utility model.

6What would this change in a real pipeline?

ALeRCE probabilities→ Calibration layer→ Reliability checker→ Ranked decision queue
High reliability
  • Auto-accept broker label
  • Routine photometric monitoring
  • No unnecessary manual review
Low reliability
  • Wait for more detections / second broker
  • Human review, host-galaxy context
  • Spectroscopy only when scientifically valuable

For the same review budget, the checker concentrates far more errors into the deferred queue than raw confidence.

Historical alert-stream replay is required to establish real-time telescope-level benefit. Next: reconstruct probabilities after 2, 5, 10 detections · fixed nightly budget · errors found per 100 reviewed · rare-transient recovery · later observing season.

7Conclusions

  • 1. ALeRCE frequently ranks the correct class first, but its confidence values are systematically too low.
  • 2. Calibration repairs the interpretation of numerical probability gates without changing the top-ranked class.
  • 3. A post-hoc checker using the complete 15-class probability vector identifies unreliable predictions better than raw confidence or predicted-class identity alone.
  • 4. Confidence-based selective classification cannot replace explicit novelty detection when the true class is absent from the taxonomy.
Calibrated probabilities decide how much to trust a prediction. A reliability checker decides which predictions to trust. A novelty detector is still needed for classes the broker cannot represent.
A functioning alert classifier is not automatically functioning decision infrastructure.
